# 社群与反馈

## 问题反馈

优先用 GitHub Issues：<https://github.com/maning636/laoma-bid-skills/issues>

提 issue 时请带上：

- Python 版本
- 操作系统
- 最小复现片段（能贴输入就贴输入）
- 完整报错栈

## 贡献

见 `CONTRIBUTING.md`。简单说：

1. Fork → 建分支 → 改代码
2. **每个新技能必须同时给 `SKILL.md` + 至少 3 条测试**
3. 跑 `pytest` 全绿再提 PR

然后在本文件与 `README.md` 里引用。
